# Один день в гимназии

Пиксельная RPG про один очень обычный школьный день Ромы Ковгана: уроки, перемены, байт,
вейп, телефон под партой, Эль-Класико на физре и пять концовок. Игра для ПК, в браузере.

## Как запустить
1. Скачай файл `dist/index.html` (на GitHub: открой файл → кнопка «Download raw file»).
2. Открой его двойным кликом. Нужен Chrome, Edge или Firefox. Интернет не нужен.
3. Нажми любую клавишу (так браузер разрешит звук) → «Новая игра».

Код дня (6 символов) задаёт все случайности дня. Отправь код другу — у него будет тот же день.
Сохранение автоматическое (в начале каждого урока и перемены). Код сохранения можно скопировать
в меню паузы и вставить в главном меню («Ввести код сохранения»).

## Управление
| Клавиша | Что делает |
|---|---|
| Стрелки / WASD | ходить, выбирать в меню |
| Z / Enter / Пробел | говорить, подтвердить, главное действие |
| X / Esc | назад, пропустить печать текста, пауза |
| Shift | бег (и рывок в футболе) |
| C | второе действие в мини-играх (удар в футболе, отмена в блок-пазле) |
| Tab | схема школы и расписание |
| M | звук вкл/выкл |
| F | полный экран |

В начале каждой мини-игры показаны её клавиши. В футболе: Z — пас, C — удар (держи — сильнее),
X — отбор (сзади — фол!), Shift — рывок (тратит выносливость).

## Как добавить свои реплики
Все тексты лежат в `data/dialogs/*.txt` (например, `break1.txt` — разговоры на 1-й перемене,
`lesson3.txt` — урок русского, `bait_igor.txt` — байт-дуэль с Игорем, `football.txt` — футбол).
Формат простой:

```
=== метка                      ← начало сцены
@igor [happy] Текст реплики     ← кто говорит и с каким лицом (norm, happy, angry, surprised, dumb)
@narrator Текст без говорящего
# stress +5, aura -3            ← изменить статусы
? Что ответить?                 ← вопрос
* Вариант ответа => другая_метка {aura +3} {if vape>0}
-> другая_метка                 ← перейти
```

Добавь строчку `@igor [happy] ...` в нужную сцену — и Игорь будет говорить и её (в байт-дуэлях и
репликах соперника фраза выбирается случайно из всех строк метки). Если в файле ошибка, игра
покажет номер строки. После правки нужно пересобрать игру (см. ниже).

## Как дописать вопросы к тестам

Вопросы лежат в папке `data/tests/`, по файлу на предмет (`algebra.txt`, `russian.txt`, `english.txt` и т. д.).
На уроке с тестом игра берёт 10 случайных вопросов (по коду недели). Формат простой:

```
? Чему равен log₂ 8?
+ 3
- 4
- 2
- 8
```

- строка с `?` — вопрос;
- строка с `+` — правильный ответ (ровно один);
- строки с `-` — неправильные ответы (всего вариантов должно быть 4);
- пустые строки и строки, которые начинаются с `//`, — пропускаются.

Порядок вариантов в игре перемешивается, так что правильный можно писать первым. После правки
пересоберите игру (см. ниже). Проверка, что всё записано верно: `npm test`.

## Как пересобрать игру
Нужен Node.js 18+.
```
npm install
npm run build      ← соберёт новый dist/index.html
npm test           ← проверит диалоги и логику
```
`npm run dev` — запуск для разработки с автообновлением.

## Для разработчика
- Спецификация — `GAME_SPEC.md`, этапы — `STAGES.md`, журнал — `PROGRESS.md`, скриншоты — `docs/screenshots/`.
- Отладочное меню — открой игру с `?debug` в адресе (`index.html?debug`) и нажми `` ` ``: любой урок,
  перемена, локация, мини-игра с любым соперником, матч «ИИ против ИИ», любая концовка, статусы.
- Проверки: `node tools/check_stage4.mjs` (мини-игры), `node tools/check_stage5.mjs` (футбол),
  `node tools/check_stage6.mjs` (концовки, сохранение, итоги), `node tools/bot_day.mjs КОД` (бот на весь день).
- Баланс: `node tools/balance_minigames.mjs`, `node tools/balance_football.mjs 30`, `node tools/sim_days.mjs 50`.
