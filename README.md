# Один день в гимназии

Пиксельная RPG про одну очень обычную учебную неделю Ромы Ковгана: уроки и тесты, перемены,
байт, вейп, телефон под партой, плавание, классный час, два «Эль-Класико» на физре и четыре
концовки — от «Гордости семьи» до «Папочка зол». Игра для ПК, в браузере. Версия 2.

## Как запустить
1. Скачай файл `dist/index.html` (на GitHub: открой файл → кнопка «Download raw file»).
2. Открой его двойным кликом. Нужен Chrome, Edge или Firefox. Интернет не нужен.
3. Нажми любую клавишу (так браузер разрешит звук) → «Новая игра».

Неделя — понедельник–пятница, каждый день со своим расписанием. Концовка зависит от среднего
балла за неделю: больше 8,0 — «Гордость семьи», 6,0–8,0 — «Поступаю в БНТУ», 4,0–5,99 —
«Дорога в хабзу», меньше 4,0 — «Папочка зол».

Код недели (6 символов) задаёт все случайности. Отправь код другу — у него будет та же неделя.
Сохранение автоматическое (в начале каждого урока и перемены). Код сохранения можно скопировать
в меню паузы и вставить в главном меню («Ввести код сохранения»).

## Управление
| Клавиша | Что делает |
|---|---|
| Стрелки / WASD | ходить, выбирать в меню |
| Z / Enter / Пробел | говорить, подтвердить, главное действие |
| X / Esc | назад, пропустить печать текста, пауза |
| Shift | бег (и рывок в футболе) |
| C | второе действие в мини-играх (удар в футболе, отмена в блок-пазле) |
| Tab | схема школы и статусы |
| M | звук вкл/выкл |
| F | полный экран |

В начале каждой мини-игры показаны её клавиши. В футболе: Z — пас, C — удар (держи — сильнее),
X — отбор (сзади — фол), Shift — рывок. Штрафной и пенальти: первое Z — направление, второе Z — сила.

## Вкладки «Расписание» и «Дневник»
Обе есть в меню паузы (Esc) и в «Настройках» главного меню.
- **Расписание** — уроки всей недели, сегодняшний день подсвечен, текущий урок в рамке.
  Там же видно, где будет следующий урок.
- **Дневник** — экран iPhone Ромы: все оценки недели и средний балл (по нему выбирается
  концовка). Если телефон сел — дневник не открыть, заряжайся в библиотеке или проси пауэрбанк.

## Как добавить свои реплики
Все тексты лежат в `data/dialogs/*.txt`. Главные файлы:
- `talk_<имя>.txt` — разговоры на переменах с каждым (например, `talk_igor.txt`), метки `t1`, `t2`, …;
- `bait_<имя>.txt` — фразы рейджбайта против этого персонажа и его ответы;
- `group.txt`, `football_talk.txt`, `react.txt`, `gossip.txt` — групповые сценки, споры о футболе,
  реакции на события, сплетни безымянных;
- `lesson_<предмет>.txt` — события уроков (`lesson_pe.txt` — раздевалка перед матчем);
- `football.txt` — реплики во время матча; `bus_home.txt` — дорога домой; `endings.txt` — концовки.
Подколы после матча лежат в `data/football_banter.js` (там же описано, как их писать).

Формат простой:

```
=== метка                      ← начало сцены
@igor [happy] Текст реплики     ← кто говорит и с каким лицом (norm, happy, angry, surprised, dumb)
@narrator Текст без говорящего
# stress +5, aura -3            ← изменить статусы
? Что ответить?                 ← вопрос
* Вариант ответа => другая_метка {aura +3} {if vape>0}
-> другая_метка                 ← перейти
```

Чтобы добавить новый разговор, допиши в `talk_<имя>.txt` сцену со следующим номером
(`=== t21`). В байте и репликах соперника фраза выбирается случайно из всех строк метки — можно
просто добавить строку. Если в файле ошибка, игра покажет номер строки. После правки нужно
пересобрать игру (см. ниже).

## Как дописать вопросы к тестам
Вопросы лежат в папке `data/tests/`, по файлу на предмет (`algebra.txt`, `russian.txt`, `english.txt` и т. д.).
На уроке с тестом игра берёт 10 случайных вопросов (по коду недели). Формат:

```
? Чему равен log₂ 8?
+ 3
- 4
- 2
- 8
```

- строка с `?` — вопрос;
- строка с `+` — правильный ответ (ровно один);
- строки с `-` — неправильные ответы (всего вариантов должно быть 4);
- пустые строки и строки, которые начинаются с `//`, — пропускаются.

Порядок вариантов в игре перемешивается, так что правильный можно писать первым.

## Как пересобрать игру
Нужен Node.js 18+.
```
npm install
npm run build      ← соберёт новый dist/index.html
npm test           ← проверит диалоги, тесты и логику
```
`npm run dev` — запуск для разработки с автообновлением.
